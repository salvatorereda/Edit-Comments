# Edit a Comment

The Comments panel with a thread open, built from the real `CommentContent`,
`CommentTextArea`, `SkpKebab`, `SkpButton`, `SkpDialog` and emoji picker. It
follows the RTC - GO 2026 Figma section "Edit Comments".

Every story below is the same working panel, started at a different step, so
you can click through the whole flow from any of them. You are **Maya
Sanchez**: only your own reply has a ⋮ menu, the same rule the app uses for
Delete today.

1. **Photo attached**: the new-comment box has a photo. Type a comment.
2. **Comment written**: send it with the arrow, or Return.
3. **Comment posted**: your reply is in the thread. Open its ⋮.
4. **Comment menu**: *Edit comment* or *Delete comment* (works as today).
5. **Editing**: the reply turns into an editor in place, with its photo, its
   text, + (add or update the photo), emoji, **Cancel** and **Save changes**.
   The new-comment box hides while you edit.
6. **Unsaved changes** *(proposed)*: Save changes turns on once something
   changes. It stays off if you remove both the text and the photo.
7. **Discard Changes?** *(proposed)*: Cancel or Esc after editing asks first.
   Cancel with no changes just closes the editor.
8. **Saved** *(proposed)*: the reply updates in place and its timestamp reads
   "Edited".

See **Edit Comment/Flow Diagram** for the map of these steps.
