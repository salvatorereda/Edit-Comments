# SketchUp Web UI Mocks

Welcome to your mock project! This Storybook instance imports real components
from the SketchUp Web source tree so you can explore UI changes without
modifying the original code.

## How it works

1. **Describe** the UI change you want to explore
2. **Claude creates** Vue components and stories in this project
3. **View** them here in Storybook — they hot-reload as changes are made
4. **Iterate** — describe refinements, Claude updates, you refresh

## Getting started

Ask Claude to create a mock for any part of the SketchUp Web UI. For example:

- "Show me the left toolbar with larger icons"
- "Mock up a redesigned materials panel"
- "What would the homescreen look like with a dark theme?"

Stories will appear in the sidebar on the left as they're created.
