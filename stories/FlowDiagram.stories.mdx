# Edit Comment: Flow

How a person gets from posting a reply to editing it, and every way out of
the editor. Solid steps are in the Figma mocks. Dashed steps are proposed
here to fill the gaps the mocks leave open. Click any step to open it in
**Edit Comment/Thread**.

Open questions this raises:

- **Who can edit?** The mock limits Edit to the author of a reply, the same
  rule as Delete today. The thread's first comment (the topic) has no ⋮ menu
  in the app today, so it can't be edited here either.
- **Menu order.** Edit comment is above Delete comment. Delete stays last
  because it is the destructive action.
- **"Edited" label.** Should others see that a comment changed, and when?
- **Notifications.** Does an edit notify people in the thread, or mark the
  thread unread for them?
